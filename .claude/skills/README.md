# Design skills

Third-party Claude Code skills, vendored as-is (MIT):

| Skill | Source | Use for |
|---|---|---|
| `design-taste-frontend` | [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) | Landing, blog, and marketing pages (not data dashboards) |
| `web-design-guidelines` | [vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills) | Reviewing UI code against Vercel's Web Interface Guidelines |
| `mono` | [bergside/awesome-design-skills](https://github.com/bergside/awesome-design-skills) | Monospace, high-contrast, compact reference (closest match to our look) |

SoulCurve's own design tokens win over any skill's defaults: IBM Plex Mono, the dark
surface and `soul` green in `apps/web/src/index.css` and `apps/web/src/chartTheme.ts`.
Use the skills for layout, hierarchy, states, and accessibility, not to swap fonts or colors.
